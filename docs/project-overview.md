
# Project Overview

## Project Title
AI-Powered Anomaly Detection for Industrial Control Systems

## 1. Introduction

Industrial Control Systems (ICS) are used to monitor and control physical processes in industries such as water treatment, manufacturing and energy production.

These systems rely on components such as Programmable Logic Controllers (PLCs), sensors, actuators and Supervisory Control and Data Acquisition (SCADA) systems.

Cyberattacks against industrial systems can disrupt operations, damage equipment and affect reliability.

This project aims to develop a machine learning-based system that identifies unusual network activity in a simulated industrial environment.

## 2. Project Environment

The project will simulate a water treatment plant.

The simulated environment will include:

- PLC
- SCADA/HMI
- Water level sensors
- Pressure sensors
- Flow sensors
- Pumps
- Valves
- Industrial network communication using Modbus/TCP

## 3. Project Aim

To design and implement an AI-powered anomaly detection system that monitors industrial network traffic, identifies suspicious behaviour and alerts administrators.

## 4. Project Objectives

1. Understand the architecture of an Industrial Control System.
2. Identify important industrial assets and their vulnerabilities.
3. Perform threat modelling and risk assessment.
4. Develop a simulated industrial environment.
5. Collect normal and abnormal network traffic.
6. Train a machine learning model to detect anomalies.
7. Develop a dashboard to display suspicious activities.
8. Evaluate the system through controlled testing.
9. Assess how the solution supports operational resilience.

## 5. Proposed Technologies

- Python
- Scikit-learn
- OpenPLC
- PyModbus
- Wireshark
- Streamlit
- Git and GitHub

## 6. Project Scope

The project will use a simulated industrial environment.

All security testing will be conducted in an isolated and authorised lab.

The AI system will detect and report suspicious activity. It will not automatically control industrial equipment.

## 7. Expected Outcome

A functional prototype that monitors simulated industrial network activity, detects anomalies using machine learning and displays alerts through a dashboard.
