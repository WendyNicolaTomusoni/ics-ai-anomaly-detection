
# AI-Powered Anomaly Detection for Industrial Control Systems

A cybersecurity project focused on detecting unusual network activity in a simulated Industrial Control System (ICS) using machine learning.

## Project Scenario

A simulated water treatment plant containing industrial components such as PLCs, sensors, pumps, valves and a SCADA monitoring system.

## Main Goal

Develop a Python-based anomaly detection system that monitors industrial network traffic, identifies suspicious behaviour and alerts administrators.

## Planned Features

- Simulated industrial environment
- Modbus/TCP communication
- Network traffic collection
- Machine learning anomaly detection
- Suspicious activity alerts
- Monitoring dashboard
- Security and resilience testing

## Technology Stack

- Python
- Scikit-learn
- OpenPLC
- PyModbus
- Wireshark
- Streamlit
- Git and GitHub

Stage 1: Project setup and repository creation.

## Safety

All simulations and security testing will be performed in an isolated, authorised environment. The prototype is for monitoring and alerting, not direct industrial control.
